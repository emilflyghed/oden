# Skills

This directory holds provider-neutral Oden skills.

Read the skill that matches the current task:

- `skill-template.md`: structure for new Oden skills.
- `codebase-locator.md`: find where relevant files, symbols, docs, and tests live.
- `codebase-analyzer.md`: explain how selected files or flows work.
- `web-researcher.md`: verify current external facts with sources.
- `browser-researcher.md`: inspect dynamic or visual browser state under browser safety gates.
- `provider-bundle-maintainer.md`: keep provider export bundles aligned with canonical Oden docs.

These skills are canonical markdown instructions. Provider-specific skill formats belong in provider bundles, not in this directory.
