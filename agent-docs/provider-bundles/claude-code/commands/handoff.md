# Oden Handoff

Read `agent-docs/workflows/handoff.md` and create or update a handoff in `agent-docs/handoffs/`.

Include current goal, current step, completed work, files changed, commands run, known failures, decisions, open questions, constraints, and next recommended action.

Do not include secrets, credentials, tokens, cookies, or private keys.
