# Examples

This directory contains copyable examples for using Oden.

## Files

- `start-step-example.md`: how a user starts a numbered implementation step and what the agent should report.
- `provider-install-example.md`: generic provider installation flow for global or project-level agent configuration.
- `browser-research-example.md`: safe public browser research, evidence recording, and permission stops.
- `task-intake-example.md`: how a non-step request becomes a small working contract.
- `failure-recovery-example.md`: how to classify and recover from a failed check.
- `review-example.md`: how to self-review or report review findings.

## Boundaries

Examples are illustrative. They do not prove that provider installation, browser automation, or external services were tested.

Do not include real credentials, account data, payment details, private URLs, cookies, tokens, or authenticated screenshots in examples.
