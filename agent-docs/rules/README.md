# Rules

This directory holds canonical Oden rules.

Read these files before substantial work:

- `agent-behavior.md`: collaboration and scope discipline.
- `safety-permissions.md`: destructive, credential-sensitive, and irreversible action gates.
- `verification.md`: verification levels and reporting expectations.
- `common-mistakes.md`: durable lessons future agents must not repeat.
- `code-quality.md`: lint, error handling, comments, and language guidance.
- `browser-safety.md`: guarded browser research/testing rules.

The stable common mistakes file is `agent-docs/rules/common-mistakes.md`.
