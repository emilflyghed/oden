# Workflows

This directory holds Oden's provider-neutral workflows.

Read the workflow that matches the current task:

- `task-intake.md`: clarify substantial non-step work before choosing a workflow.
- `research.md`: map facts without silently implementing.
- `plan.md`: turn facts into scoped, verifiable, resumable steps.
- `implement.md`: execute accepted plans while preserving scope and user edits.
- `validate.md`: report exact checks, results, and residual risk.
- `failure-recovery.md`: classify failed checks and recover without random retries.
- `review.md`: review code/docs/config work or self-review before final completion.
- `checkpoint.md`: write short resumable state snapshots.
- `handoff.md`: prepare another agent to continue incomplete work.
- `claim-evidence.md`: connect important claims to sources, confidence, verification, and risk.
- `start-step.md`: respond when the user says `Start step X`.

These workflows are provider-neutral and do not require a graph runtime.
