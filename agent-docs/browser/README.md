# Browser

This directory holds guarded browser research and testing guidance.

Browser use is allowed for public research, inspection, screenshots, page-state verification, and trying Oden workflows when no irreversible or externally visible action occurs.

Explicit user permission is required before publishing, signing up, entering credentials, making payments, sending messages, changing account settings, deleting data, submitting information, accepting terms, or performing any irreversible or externally visible action.

## Files

- `permissions.md`: browser action policy and required user confirmation points.
- `research-playbook.md`: how to use browser access for research and safe testing.
- `site-skill-template.md`: template for durable site-specific browser notes.
- `evidence-template.md`: template for recording browser observations.

Browser docs are instructions only. They do not install, launch, or configure an executable browser harness.
